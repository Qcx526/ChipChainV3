# Synthetic examples

`cases/` 中的三个 JSON 展示 hardware-only、firmware-only、paired CaseBundle 的 schema 与生命周期。
它们是 synthetic metadata examples，`fixtures/...` 路径是示意引用，不保证存在，也不是可执行的 ELF。
不要用真实样本替换它们，或将它们视为真实分析结果。

项目内真实材料和可以解析到本地文件的 CaseBundle 视图见 [samples workspace](../samples/README.md)。
`tests/` 继续保存小型 synthetic 测试材料；实际分析运行输出在 `output/`。
