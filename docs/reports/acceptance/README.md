## 每份报告先回答六个问题

1. 分析的是什么材料？
2. 这次确实发现了什么？
3. 哪些是模型解释、猜测，或者已经发现的错误？
4. 证据足以支持到哪一步？
5. 这一阶段可以验收什么、不能验收什么？
6. 下一步具体需要什么验证？

正文使用中文和必要的数值；完整 ID、证据引用与 SHA 放在附录。
“机器检查通过”意味着相应字段或引用符合检查规则，不能翻译成“人工认可”或“漏洞已验证”。
格式参考 [后续报告模板](report-template.md)。

## 当前交付方式

本版由助手读取现有报告和已记录审查后撰写，保留纠错和不确定性，未调用额外模型。
它是三份实际报告的中文验收版与统一模板，**尚未在 workflow 中实现自动中文生成**。
后续报告交付应同时包含机器 JSON 与按此模板编写的中文验收版；不能仅翻译字段标题后原样堆砌英文正文。
程序化批量生成将来若实现，也必须检查原始条目覆盖、run 绑定、拒绝状态与解释的事实边界。

[manifest.json](manifest.json)记录所用源文件 SHA、run 和全部 50 个主要条目的中英文身份映射。
原始 JSON、支持检查、研究文档、reviewed 输出均保持不变，没有重新运行分析。
网页无外部字体、脚本或服务依赖；可以本地打开，使用浏览器打印保存 PDF。
单独发送 HTML 时正文仍可读，但源文件复核链接需要一并提供项目目录。

需要逐字段学习原始结构时，再阅读 [技术阅读教程](../../tutorials/report-walkthrough/README.md)。
